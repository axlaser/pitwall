# pitwall 1.0.0

pitwall 1.0.0 is the first release as a Claude Code plugin. It replaces claude-statusline, both the per-platform status-line scripts and the Rust binary that followed them, with hooks that draw into Claude Code itself: a live box above the prompt, a docked side panel for rate limits, the session's cost, the prompt cache, the advisor and subagents, fourteen themes in `/theme`, and alert sounds.

## Installing

```text
/plugin install pitwall --marketplace axlaser/pitwall
```

It needs Claude Code 2.1.299 or later. Restart once afterwards so the themes appear in `/theme`. The settings are in `/config`, under pitwall.

## Coming from claude-statusline

**Uninstall it before installing pitwall.** Its entries stay in `~/.claude/settings.json` until its own uninstaller removes them: its `statusLine` keeps drawing under the prompt, its hooks keep running on every tool call and prompt, and its `subagentStatusLine` outranks pitwall's, so the agent rows under the prompt come back.

The uninstall commands in the old README point at `master`, which no longer holds those files. `curl -fsSL` prints nothing on a 404 and `bash` exits 0, so they look like they ran and do nothing. The commands below are pinned to the last commit of each version, so they keep working.

Each line runs only if its version is installed, so paste both lines for your system.

### macOS

```bash
[ -e ~/.claude/bin/claude-statusline ] && curl -fsSL https://raw.githubusercontent.com/axlaser/pitwall/67f0e5bf0df2b81bb3286030fc701feb60706ef3/install/uninstall.sh | bash
[ -e ~/.claude/statusline.sh ] && curl -fsSL https://raw.githubusercontent.com/axlaser/pitwall/e49f202b4537d583f4bc2ee3c02e9693e4374963/macos/uninstall.sh | bash
```

### Linux

```bash
[ -e ~/.claude/bin/claude-statusline ] && curl -fsSL https://raw.githubusercontent.com/axlaser/pitwall/67f0e5bf0df2b81bb3286030fc701feb60706ef3/install/uninstall.sh | bash
[ -e ~/.claude/statusline.sh ] && curl -fsSL https://raw.githubusercontent.com/axlaser/pitwall/e49f202b4537d583f4bc2ee3c02e9693e4374963/linux/uninstall.sh | bash
```

### Windows (PowerShell)

```powershell
if (Test-Path "$HOME\.claude\bin\claude-statusline.exe") { irm https://raw.githubusercontent.com/axlaser/pitwall/67f0e5bf0df2b81bb3286030fc701feb60706ef3/install/uninstall.ps1 | iex }
if (Test-Path "$HOME\.claude\statusline.ps1") { irm https://raw.githubusercontent.com/axlaser/pitwall/e49f202b4537d583f4bc2ee3c02e9693e4374963/windows/uninstall.ps1 | iex }
```

The binary's uninstaller asks whether to remove the notification tools its installer added. The scripts' uninstaller leaves jq, terminal-notifier, libnotify and BurntToast in place; `Uninstall-Module BurntToast` removes the last.

Restart Claude Code after uninstalling, then install pitwall.

## Reporting a problem

A hook that fails leaves a dim `pitwall: …` line in the transcript, and `claude --debug` logs the reason. Open an issue at <https://github.com/axlaser/pitwall/issues> with both and your `claude --version`.
